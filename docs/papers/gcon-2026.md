[Published paper / DOI](https://doi.org/10.1109/GCON69192.2026.11648274)

## What this part of the project investigates

Instead of duplicating the full AES round datapath, the design reuses sequential transformation and key-expansion units. The architecture trades more cycles per block for a compact hardware implementation. Start with the [AES chapter](../01-aes-core.md), then follow the controller and its helper units.

## How it connects to the next paper

The [ISAIA work](isaia-2026.md) uses the reusable AES block as an accelerator inside a RISC-V system, adds CTR processing and provides MMIO/custom-instruction control. That is an integration step, not a replacement of the AES algorithm.
